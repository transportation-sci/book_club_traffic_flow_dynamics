# Book Club Traffic Flow Dynamics


This repo contains the relevant files and code for the Traffic Flow
Dynamics book club. It uses `uv` for Python virtual environment.
[Install `uv`](https://docs.astral.sh/uv/getting-started/installation/)
and then run `uv sync` in terminal to install the relevant packages.

## Data

NGSIM Data can be obtained here:
https://data.transportation.gov/Automobiles/Next-Generation-Simulation-NGSIM-Vehicle-Trajector/8ect-6jqj/about_data
